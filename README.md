# Sistem Panen Digital

**Deskripsi :**
Proyek ini adalah program Python sederhana untuk menghitung total pendapatan dari hasil panen. Program ini juga dilengkapi dengan fitur perhitungan diskon.
**Cara Menjalankan Program**
1. Pastikan anda memiliki Python yang sudah terinstall
2. Jalankan file TTS_4_SITA_ASYAHIR_NOMOR_3 melalui terminal
3. Masukkan berat panen dan harga per kg sesuai instruksi di layar
